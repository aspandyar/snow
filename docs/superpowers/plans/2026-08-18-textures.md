# Текстуры и материалы — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Заменить однотонные материалы настоящими PBR-картами, наладить воспроизводимую добычу текстур и убрать мыло анизотропной фильтрацией.

**Architecture:** Скрипт `scripts/download-textures.mjs` качает CC0-материалы с ambientCG, распаковывает, конвертирует в WebP через sharp и кладёт в `public/textures/`. Готовые WebP хранятся в репозитории. Компоненты берут пути из конфига; метраж на повтор считается чистой функцией и покрыт тестом, наличие файлов — тоже.

**Tech Stack:** three 0.185.1, @react-three/fiber 9.7.0, @react-three/drei 10.7.8, sharp 0.35.3, Vitest 4.1.10.

Спека: `docs/superpowers/specs/2026-08-18-textures-design.md`.

## Global Constraints

- **Все числа сцены — только в `lib/config.ts`.** Исключение: настройки конвертации живут в самом скрипте — `lib/config.ts` попадает в браузерный пакет, и тащить туда параметры сборки значит отдавать их пользователю впустую.
- **Каждое число в конфиге сопровождается комментарием**: почему именно столько и что сломается иначе.
- **Комментарии, имена в конфиге, спеки и планы — по-русски.**
- **Сообщения коммитов и тексты PR — ПО-АНГЛИЙСКИ.** Это соглашение проекта, записанное в `AGENTS.md`. Внутренности остаются русскими.
- **Пути и имена файлов — латиницей.**
- **Версии пакетов, влияющих на картинку, закрепляются точно.**
- **База — `master`**, ветка `ft/textures`.
- **Скриншоты снимает контроллер.** Сервер разработки поднят на порту 3000, исполнители его не трогают.

Добыто до написания плана, перепроверять не нужно:

- `sharp@0.35.3` ставится и конвертирует в WebP на Node 25.7.0;
- адрес загрузки ambientCG: `https://ambientcg.com/get?file=<Идентификатор>_2K-PNG.zip`;

- материалы льда на ambientCG: `Ice002`, `Ice003`, `Ice004`.

- [ ] **Шаг 2: Написать скрипт**

Файл `scripts/download-textures.mjs`:

```js
/**
 * Добывает CC0-материалы с ambientCG, конвертирует в WebP и раскладывает
 * в public/textures.
 *
 * Запускается ВРУЧНУЮ: `npm run textures`. Частью сборки скрипт быть не
 * должен. Если сделать его частью, деплой начнёт зависеть от чужого
 * сайта: сменится адрес, упадёт источник, включится ограничение по
 * частоте запросов — и сборка ляжет на хостинге, а не у вас. Готовые
 * WebP лежат в репозитории.
 */
import { execFile } from 'node:child_process'
import { mkdir, rm, writeFile } from 'node:fs/promises'
import path from 'node:path'
import { promisify } from 'node:util'

import sharp from 'sharp'

const выполнить = promisify(execFile)

const КОРЕНЬ = path.resolve(import.meta.dirname, '..')
const ВЫХОД = path.join(КОРЕНЬ, 'public', 'textures')
const ВРЕМЕННАЯ = path.join(КОРЕНЬ, '.textures-tmp')

/**
 * Качество WebP по типам карт.
 *
 * Живёт здесь, а не в lib/config.ts, намеренно: конфиг попадает в
 * браузерный пакет, и настройки сборки в нём — балласт, который скачает
 * каждый посетитель.
 *
 * У нормалей качество выше остальных: артефакты сжатия в карте нормалей
 * превращаются не в размытие, а в рябь освещения — глаз читает её как
 * грязь на поверхности.
 */
const КАЧЕСТВО = { color: 82, 'normal-gl': 92, roughness: 82 }

const НАБОРЫ = [
  {
    источник: 'Snow006',
    префикс: 'snow',
    // NormalGL, а НЕ NormalDX. Отличаются знаком зелёного канала.
    // С DX свет на неровностях ложится наизнанку: выпуклости читаются
    // впадинами. На однородном насте это почти незаметно, и ошибка
    // доживает до этапа, где её уже никто не свяжет с текстурами.
    карты: { Color: 'color', NormalGL: 'normal-gl', Roughness: 'roughness' },
  },
  {
    источник: 'Ice002',
    префикс: 'ice',
    // Кирпичу нужны только нормали: цвет и шероховатость у него свои,
    // подобранные так, чтобы он оставался темнее снега.
    карты: { NormalGL: 'normal-gl' },
  },
]

async function добыть(набор) {
  const архив = path.join(ВРЕМЕННАЯ, `${набор.источник}.zip`)
  const адрес = `https://ambientcg.com/get?file=${набор.источник}_2K-PNG.zip`

  console.log(`качаю ${набор.источник}`)
  await выполнить('curl', ['-sL', '--max-time', '300', '-o', архив, адрес])
  await выполнить('unzip', ['-qo', архив, '-d', path.join(ВРЕМЕННАЯ, набор.источник)])

  for (const [исходная, имя] of Object.entries(набор.карты)) {
    const вход = path.join(
      ВРЕМЕННАЯ,
      набор.источник,
      `${набор.источник}_2K-PNG_${исходная}.png`,
    )
    const выход = path.join(ВЫХОД, `${набор.префикс}-${имя}.webp`)
    await sharp(вход).webp({ quality: КАЧЕСТВО[имя] }).toFile(выход)
    console.log(`  ${path.basename(выход)}`)
  }
}

await rm(ВРЕМЕННАЯ, { recursive: true, force: true })
await mkdir(ВРЕМЕННАЯ, { recursive: true })
await mkdir(ВЫХОД, { recursive: true })

for (const набор of НАБОРЫ) await добыть(набор)

await writeFile(
  path.join(ВЫХОД, 'SOURCES.md'),
  [
    '# Откуда взяты текстуры',
    '',
    'Материалы с ambientCG под лицензией CC0: использование без',
    'ограничений и без указания авторства.',
    '',
    ...НАБОРЫ.map((н) => `- \`${н.префикс}-*\` — ambientCG ${н.источник}`),
    '',
    'Обновить набор: `npm run textures`.',
    '',
  ].join('\n'),
)

await rm(ВРЕМЕННАЯ, { recursive: true, force: true })
console.log('готово')
```

- [ ] **Шаг 3: Написать расчёт повторов**

Файл `lib/textures/tiling.ts`:

```ts
/** Сколько раз текстура укладывается вдоль стороны поверхности.
 *
 *  Метраж на повтор — вторая вещь, которую нужно проверять, когда
 *  «текстуры 4K, а всё равно мыло». Тайл в девять метров теряет детали
 *  при любом разрешении: один пиксель текстуры растягивается на
 *  несколько пикселей кадра, и добавлять пиксели в исходник бесполезно. */
export function числоПовторов(сторона: number, метраж: number): number {
  if (метраж <= 0) {
    throw new Error('метраж на повтор должен быть положительным')
  }
  return сторона / метраж
}
```

export const текстуры = {
  земля: {
    /** Пути к картам от корня public. */
    цвет: '/textures/snow-color.webp',
    нормали: '/textures/snow-normal-gl.webp',
    шероховатость: '/textures/snow-roughness.webp',

    /** Сколько метров приходится на один повтор текстуры. Вторая вещь,
     *  которую проверяют при мыле после анизотропии: тайл в девять
     *  метров теряет детали при любом разрешении карты. Меньше двух —
     *  рисунок начинает повторяться заметной сеткой, и это видно на
     *  дальних планах. Компромисс, а не оптимум. */
    метраж: 3,
  },

  кирпич: {
    нормали: '/textures/ice-normal-gl.webp',

    /** Метраж для кирпича считается от его ширины, а не от стороны
     *  плоскости: кирпич мелкий, и повтор в три метра растянул бы одну
     *  текстуру на десяток кирпичей. */
    метраж: 0.5,

    /** Сила рельефа нормалей. Единица даёт исходный рельеф материала,
     *  который для льда слишком груб: кирпич выглядит колотым камнем.
     *  Ноль возвращает идеально гладкую поверхность, по которой сразу
     *  видно компьютерную графику. */
    сила: 0.35,
  },
}

- [ ] **Шаг 5: Подключить карты к земле**

В `components/scene/Snowfield.tsx` загрузить карты через `useTexture` из drei
и настроить их в `useLayoutEffect`:

```tsx
  const карты = useTexture({
    map: текстуры.земля.цвет,
    normalMap: текстуры.земля.нормали,
    roughnessMap: текстуры.земля.шероховатость,
  })
  const { gl } = useThree()

  useLayoutEffect(() => {
    const повторов = числоПовторов(рельеф.размер, текстуры.земля.метраж)

    for (const карта of [карты.map, карты.normalMap, карты.roughnessMap]) {
      карта.wrapS = RepeatWrapping
      карта.wrapT = RepeatWrapping
      карта.repeat.set(повторов, повторов)

      // Анизотропная фильтрация — ПЕРВОЕ, что нужно включать при мыле.
      // Камера смотрит на снег скользяще, почти вдоль поверхности, и без
      // неё земля мылится независимо от разрешения карты: проблема не в
      // количестве пикселей, а в том, как они усредняются вдоль вытянутой
      // в перспективе ячейки. Значение берётся из возможностей видеокарты:
      // запрошенное сверх поддерживаемого молча игнорируется.
      карта.anisotropy = gl.capabilities.getMaxAnisotropy()

      карта.needsUpdate = true
    }

    // Цветовая карта декодируется как sRGB, остальные обязаны остаться
    // линейными. Если пропустить нормали через sRGB, освещение поедет
    // едва заметно и повсеместно — а искать причину будут в свете.
    карты.map.colorSpace = SRGBColorSpace
    карты.normalMap.colorSpace = NoColorSpace
    карты.roughnessMap.colorSpace = NoColorSpace
  }, [карты, gl])
```

и передать карты в `meshStandardMaterial` вместо однотонного цвета,
сохранив `roughness` и `metalness` из конфига как множители.
