# Следы на снегу — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Снег мнётся под курсором и сам затягивается за несколько секунд.

**Architecture:** Точка под курсором ищется маршем луча по функции высоты — чистая функция, покрытая тестами. След копится на двумерном холсте, который каждый кадр заливается почти прозрачной краской фона: затухание получается само, без таймеров и списка точек. Холст отдаётся материалу земли картой смещения и загружается в видеопамять через кадр.

**Tech Stack:** three 0.185.1, @react-three/fiber 9.7.0, Vitest 4.1.10.

Спека: `docs/superpowers/specs/2026-08-20-footprints-design.md`.

## Global Constraints

- **Все числа сцены — только в `lib/config.ts`**, каждое с комментарием «почему именно столько и что сломается иначе».
- **Комментарии и документация — по-русски. Коммиты и PR — ПО-АНГЛИЙСКИ** (`AGENTS.md`).
- **Ни одной строки самописного шейдера.** Смещение по карте — встроенная возможность материала.
- **`useFrame` только с приоритетом по умолчанию.**
- **Геометрия объявляется в разметке**, а не создаётся императивно: R3F убирает только то, что создал сам.
- **База — `master`**, ветка `ft/footprints`.
- **Скриншоты снимает контроллер на СОБРАННОЙ версии** — сервер разработки теряет контекст WebGL. Исполнители серверы не трогают.

## Задача 1: Поиск точки под курсором маршем луча

**Files:** `lib/terrain/raycast.ts`, `tests/raycast.test.ts`

**Interfaces:** produces
`найтиТочкуНаЗемле(начало, направление, высота, п): { x: number; y: number; z: number } | null`
где `п = { шаг: number; дальность: number; уточнений: number }`.

- [ ] **Шаг 1: Написать падающий тест**

Файл `tests/raycast.test.ts`:

```ts
import { describe, expect, it } from 'vitest'

import { найтиТочкуНаЗемле } from '@/lib/terrain/raycast'

const п = { шаг: 1.5, дальность: 250, уточнений: 12 }

/** Ровная земля на нуле — простейшая проверяемая поверхность. */
const плоская = () => 0

/** Наклон вдоль X: высота растёт вместе с координатой. */
const наклон = (x: number) => x * 0.1

describe('марш луча по функции высоты', () => {
  it('луч сверху вниз попадает на поверхность', () => {
    const т = найтиТочкуНаЗемле({ x: 0, y: 10, z: 0 }, { x: 0, y: -1, z: 0 }, плоская, п)
    expect(т).not.toBeNull()
    expect(т!.y).toBeCloseTo(0, 3)
  })

  it('найденная точка ЛЕЖИТ на поверхности, а не рядом', () => {
    // Главный тест: если высота найденной точки не совпадает с функцией
    // высоты в ней же, курсор будет мять снег не там, куда показывает.
    const т = найтиТочкуНаЗемле({ x: -20, y: 30, z: 0 }, { x: 0.4, y: -1, z: 0 }, наклон, п)
    expect(т).not.toBeNull()
    expect(т!.y).toBeCloseTo(наклон(т!.x), 2)
  })

  it('луч, направленный от земли, не находит ничего', () => {
    expect(найтиТочкуНаЗемле({ x: 0, y: 5, z: 0 }, { x: 0, y: 1, z: 0 }, плоская, п)).toBeNull()
  })

  it('луч выше поверхности и параллельный ей не находит ничего', () => {
    expect(найтиТочкуНаЗемле({ x: 0, y: 5, z: 0 }, { x: 1, y: 0, z: 0 }, плоская, п)).toBeNull()
  })

  it('луч, начинающийся под землёй, не находит ничего', () => {
    // Иначе камера, случайно оказавшаяся ниже снега, дала бы точку
    // позади себя.
    expect(найтиТочкуНаЗемле({ x: 0, y: -2, z: 0 }, { x: 0, y: -1, z: 0 }, плоская, п)).toBeNull()
  })

  it('число обращений к функции высоты ограничено', () => {
    // Ради этого всё и затевалось: пересечение с геометрией стоило бы
    // триста тысяч проверок треугольников на каждое движение мыши.
    let вызовов = 0
    const считающая = (x: number) => {
      вызовов++
      return наклон(x)
    }
    найтиТочкуНаЗемле({ x: 0, y: 40, z: 0 }, { x: 0, y: -1, z: 0 }, считающая, п)
    expect(вызовов).toBeLessThan(п.дальность / п.шаг + п.уточнений + 5)
  })

  it('не зацикливается при нулевом направлении', () => {
    expect(найтиТочкуНаЗемле({ x: 0, y: 5, z: 0 }, { x: 0, y: 0, z: 0 }, плоская, п)).toBeNull()
  })
})
```

- [ ] **Шаг 2: Убедиться, что тесты падают**

```bash
npx vitest run tests/raycast.test.ts
```

- [ ] **Шаг 3: Реализовать**

Файл `lib/terrain/raycast.ts`. Алгоритм: идти по лучу шагами, на каждом
сравнивать высоту луча с высотой снега; как только луч оказался ниже —
пересечение между этим шагом и предыдущим, уточнить делением отрезка
пополам заданное число раз.

Обязательно: направление нормализуется внутри; нулевое направление
возвращает `null` сразу, иначе цикл никогда не сдвинется; старт под
землёй возвращает `null`.

## Задача 2: Холст следов

**Files:** `lib/footprints/trail.ts`, `components/scene/useTrail.ts`, `lib/config.ts`

**Interfaces:** produces `useКартаСледов(): CanvasTexture`

- [ ] **Шаг 1: Дополнить конфиг**

```ts
export const следы = {
  /** Сторона холста в пикселях. При 400 метрах равнины это 0.78 метра
   *  на пиксель — соразмерно сетке земли, у которой ячейка чуть больше
   *  метра. Рисовать точнее, чем сетка умеет показать, бессмысленно:
   *  вершин под мелким пятном просто нет. */
  размерХолста: 512,

  /** Радиус пятна под курсором, метры. Меньше двух — вмятина попадает
   *  между вершинами сетки и не появляется вовсе. Больше шести — снег
   *  проминается корытом, и это читается не следом, а обвалом. */
  радиусПятна: 3,

  /** Яркость пятна, доля. Связана с прозрачностью заливки: если пятно
   *  ярче, чем гаснет, след не затянется никогда и равнина покроется
   *  коркой. Настраивать эти два числа только вместе. */
  яркостьПятна: 0.5,

  /** Прозрачность заливки фоном каждый кадр. Это и есть весь механизм
   *  затухания: старые пятна выцветают сами, без таймеров и списка
   *  точек. Больше 0.1 — след гаснет быстрее, чем зритель успевает его
   *  заметить. Ноль — не гаснет никогда. */
  затухание: 0.03,

  /** Глубина вмятины, метры. Это масштаб карты смещения. Отрицательной
   *  быть не может: карта смещения двигает вершины ВДОЛЬ нормали, и
   *  знак задаётся не здесь, а тем, что пятно рисуется тёмным по
   *  светлому фону. Больше метра — вмятина глубже, чем сам наст. */
  глубина: 0.5,
}
```

- [ ] **Шаг 2: Операции над холстом**

`lib/footprints/trail.ts` — две функции без React:
`нарисоватьПятно(контекст, x, y, радиус, яркость)` рисует мягкое пятно
радиальным градиентом; `погаситьПолотно(контекст, размер, затухание)`
заливает всё полотно фоном с малой прозрачностью.

Фон холста — белый, пятно — тёмное: карта смещения поднимает вершины по
яркости, значит тёмное пятно даёт вмятину, а белый фон — исходный уровень.

- [ ] **Шаг 3: Хук**

`components/scene/useTrail.ts`: создаёт холст один раз, заливает его белым,
оборачивает в `CanvasTexture`, в `useFrame` находит точку под курсором
маршем луча, переводит мировые координаты в пиксели холста, рисует пятно,
гасит полотно.

**Точка вне холста отбрасывается**: курсор за краем равнины даёт координату
вне полотна, и рисование по ней либо промахнётся, либо завернётся на другую
сторону.

**Текстура помечается изменённой ЧЕРЕЗ КАДР.** Загрузка холста в
видеопамять не бесплатна, а на глаз задержка в одну шестидесятую
неразличима: след живёт секунды.

Текстуру и холст освободить при размонтировании.

## Задача 3: Карта следов на земле

**Files:** `components/scene/Snowfield.tsx`

Материал земли получает карту следов смещением. Смещение по карте —
встроенная возможность `meshStandardMaterial`, ни строчки шейдера.

Осторожно: вершины земли УЖЕ подняты функцией высоты, а смещение
добавляется поверх вдоль нормалей. Если перепутать знак или масштаб,
равнина вздуется целиком вместо того чтобы промяться под курсором.

- тесты зелёные;
- `tsc` без ошибок, сборка проходит;

- равнина не вздувается целиком;
