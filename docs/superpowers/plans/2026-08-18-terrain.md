# Заснеженная равнина — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Построить землю под сферой из одной плоскости, форма которой задана чистой функцией высоты — единственным источником истины о рельефе.

**Architecture:** `lib/terrain/height.ts` содержит чистую математику рельефа без зависимости от сцены: финитный колокол дюны, октавы шума, сборка высоты. Компонент земли деформирует вершины плоскости по этой функции. Перевод локальных координат плоскости в мировые вынесен отдельной функцией, чтобы знак глубины проверялся тестом, а не глазами.

**Tech Stack:** three 0.185.1, @react-three/fiber 9.7.0, @react-three/drei 10.7.8, simplex-noise 4.0.3, Vitest 4.1.10.

Спека: `docs/superpowers/specs/2026-08-18-terrain-design.md`.
Предыдущий этап: сфера, слита в `master`.

## Global Constraints

- **Все числа — только в `lib/config.ts`.** Исключение: тесты задают значения у себя; константы алгоритмов (множители генератора псевдослучайных чисел, орты, деление пополам, четверть оборота) настройками не являются и в конфиг не выносятся.
- **Каждое число в конфиге сопровождается комментарием**: почему именно столько и что сломается иначе.
- **Текст на русском**, пути и имена файлов латиницей, идентификаторы в коде русские.
- **Ни одной строки самописного шейдера.**
- **`useFrame` только с приоритетом по умолчанию** — любой приоритет больше нуля отключает автоматическую отрисовку в R3F, и экран чернеет без ошибок в консоли.
- **Версии пакетов, влияющих на картинку, закрепляются точно**, без диапазонов.
- **База — `master`**, ветка `ft/terrain`, этап закрывается PR со скриншотами.
- **Скриншоты снимает контроллер.** Сервер разработки поднят на порту 3000, исполнители его не трогают.

```ts
import { describe, expect, it } from 'vitest'

import { вкладДюны, type Дюна } from '@/lib/terrain/height'

// Значения задаются здесь, а не берутся из конфига: иначе тест краснеет
// от безобидной правки числа, которое человек крутит руками.
const дюна: Дюна = { x: 10, z: -4, радиус: 20, высота: 3 }

describe('колокол дюны', () => {
  it('в центре даёт полную высоту', () => {
    expect(вкладДюны(дюна, дюна.x, дюна.z)).toBeCloseTo(дюна.высота, 12)
  })

  it('на границе радиуса даёт ровно ноль', () => {
    expect(вкладДюны(дюна, дюна.x + дюна.радиус, дюна.z)).toBe(0)
  })

  it('за границей даёт РОВНО ноль, а не малую величину', () => {
    // Главный тест задачи. У гауссовой кривой здесь был бы крошечный,
    // но ненулевой хвост: гора в сотне метров приподняла бы землю под
    // сферой сначала на сантиметры, потом на дециметры, и однажды сфера
    // оказалась бы наполовину утопленной в снегу без видимой причины.
    expect(вкладДюны(дюна, дюна.x + дюна.радиус + 0.001, дюна.z)).toBe(0)
    expect(вкладДюны(дюна, дюна.x + 1000, дюна.z)).toBe(0)
    expect(вкладДюны(дюна, дюна.x, дюна.z + 1e6)).toBe(0)
  })

  it('у самой границы вклад пренебрежимо мал — смыкание без излома', () => {
    // Производная колокола на обоих концах равна нулю, поэтому дюна
    // садится на равнину гладко, а не срезанным конусом.
    const почтиГраница = вкладДюны(дюна, дюна.x + дюна.радиус * 0.99, дюна.z)
    expect(почтиГраница).toBeGreaterThan(0)
    expect(почтиГраница).toBeLessThan(дюна.высота * 0.001)
  })

  it('на вершине производная тоже нулевая — пика нет', () => {
    const центр = вкладДюны(дюна, дюна.x, дюна.z)
    const рядом = вкладДюны(дюна, дюна.x + дюна.радиус * 0.01, дюна.z)
    expect(центр - рядом).toBeLessThan(дюна.высота * 0.001)
  })

  it('вклад убывает от центра к краю', () => {
    let предыдущий = Infinity
    for (let доля = 0; доля <= 1; доля += 0.05) {
      const текущий = вкладДюны(дюна, дюна.x + дюна.радиус * доля, дюна.z)
      expect(текущий).toBeLessThanOrEqual(предыдущий)
      предыдущий = текущий
    }
  })
})
```

```ts
/** Дюна: крупная форма рельефа, расставляемая вручную.
 *
 *  Крупные формы задаются списком, а не шумом, потому что чистый шум
 *  красив, но кадром не управляет: холм не поставить туда, где он нужен
 *  по композиции. */
export type Дюна = {
  x: number
  z: number
  радиус: number
  высота: number
}

/** Вклад одной дюны в высоту точки.
 *
 *  Финитный колокол, а НЕ гауссова кривая. У гауссовой бесконечный хвост,
 *  и гора в сотне метров приподнимает землю под объектом — сначала на
 *  сантиметры, потом на дециметры. Здесь за пределами радиуса ровно ноль.
 *
 *  Множитель t²·(3 − 2t) выбран не ради красоты формулы: его производная
 *  равна нулю на обоих концах. Поэтому дюна смыкается с равниной без
 *  излома, а на вершине не образует пика. */
export function вкладДюны(дюна: Дюна, x: number, z: number): number {
  const дx = x - дюна.x
  const дz = z - дюна.z
  const расстояние = Math.sqrt(дx * дx + дz * дz)
  if (расстояние >= дюна.радиус) return 0
  const t = 1 - расстояние / дюна.радиус
  return дюна.высота * t * t * (3 - 2 * t)
}
```

- [ ] **Шаг 4: Написать реализацию**

Дописать в начало `lib/terrain/height.ts`:

```ts
import { createNoise2D } from 'simplex-noise'
```

и в конец файла:

```ts
export type ПараметрыРельефа = {
  зерно: number
  наст: {
    амплитуда: number
    частота: number
    октав: number
  }
  дюны: Дюна[]
}

/** Генератор псевдослучайных чисел mulberry32.
 *
 *  Нужен, чтобы шум был воспроизводимым: без явного зерна рельеф менялся
 *  бы при каждой перезагрузке, а тесты стали бы невоспроизводимыми.
 *
 *  Числа внутри — константы алгоритма, а не настройка сцены. В конфиг они
 *  не выносятся: менять их нельзя, от них зависит качество распределения. */
function генератор(зерно: number): () => number {
  let состояние = зерно >>> 0
  return () => {
    состояние = (состояние + 0x6d2b79f5) >>> 0
    let t = состояние
    t = Math.imul(t ^ (t >>> 15), t | 1)
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61)
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296
  }
}

/** Собирает функцию высоты рельефа.
 *
 *  Фабрика, а не готовая функция: таблица перестановок шума строится один
 *  раз здесь, а не на каждом вызове. Полученная функция — единственный
 *  источник истины о форме земли. Ею пользуются трое: земля строит по ней
 *  вершины, туман по ней стелется, курсор находит по ней точку под собой.
 *  Пока формула жила внутри компонента земли, туман ложился плоским листом
 *  и резал холмы, а курсор мял снег не там, куда указывал. */
export function создатьВысотуРельефа(п: ПараметрыРельефа): (x: number, z: number) => number {
  const шум = createNoise2D(генератор(п.зерно))

  return (x: number, z: number): number => {
    let высота = 0

    // Октавы шума дают мелкую фактуру наста: каждая следующая вдвое чаще
    // и вдвое слабее. Шум отвечает только за фактуру — крупные формы
    // расставляются дюнами, иначе кадром не управлять.
    for (let октава = 0; октава < п.наст.октав; октава++) {
      const множитель = 2 ** октава
      высота +=
        (п.наст.амплитуда / множитель) *
        шум(x * п.наст.частота * множитель, z * п.наст.частота * множитель)
    }

    for (const дюна of п.дюны) высота += вкладДюны(дюна, x, z)

    return высота
  }
}
```

```ts
describe('знак глубины', () => {
  it('мировая z равна минус локальной y', () => {
    // Плоскость создаётся лежащей в XY и поворачивается на −90° вокруг X.
    // При этом повороте локальная вершина (x, y) попадает в мировую точку

    expect(локальныеВМировые(3, 5)).toEqual([3, -5])
    expect(локальныеВМировые(-7, -2)).toEqual([-7, 2])
  })

  it('координата поперёк не меняется', () => {
    expect(локальныеВМировые(42, 0)[0]).toBe(42)
  })

  it('ноль остаётся нулём без знака', () => {
```

```ts
/** Перевод локальных координат вершины плоскости в мировые.
 *
 *  Плоскость создаётся лежащей в XY и поворачивается на −90° вокруг оси X.
 *  Поворот отображает локальную вершину (x, y) в мировую точку (x, 0, −y):
 *  мировая z равна МИНУС локальной y.
 *
 *  Вынесено отдельной функцией именно ради теста. Внутри цикла по вершинам
 *  этот знак не проверить ничем, кроме глаза, а на глаз зеркальный рельеф
 *  неотличим от правильного. */
export function локальныеВМировые(x: number, y: number): [number, number] {
  return [x, -y === 0 ? 0 : -y]
}
```

```ts
import type { Дюна } from '@/lib/terrain/height'

export const рельеф = {
  /** Зерно шума. Любое целое; важно, что оно ЕСТЬ. Без него рельеф
   *  пересобирался бы при каждой перезагрузке, кадр переставал бы
   *  повторяться, а тесты стали бы невоспроизводимыми. Менять — значит
   *  получить другой пейзаж той же породы. */
  зерно: 20260818,

  /** Сторона плоскости, метры. Одна плоскость на всю сцену, а не две:
   *  соблазн сделать мелкую площадку под сферой и грубую равнину вокруг
   *  велик, но на стыке двух сеток остаётся ровная граница, которую не
   *  убрать ничем. Меньше 300 — виден край земли. Больше 600 — сетка
   *  той же плотности перестаёт помещаться в бюджет кадра. */
  размер: 400,

  /** Сегментов сетки по стороне. Даёт ячейку около метра и порядка 295
   *  тысяч треугольников — это укладывается в бюджет: главный рычаг здесь
   *  количество пикселей, а не полигонов. Вдвое меньше — дюны становятся
   *  гранёными. Вдвое больше — миллион с лишним треугольников ради
   *  различий, невидимых с высоты камеры. */
  сегментов: 384,

  наст: {
    /** Амплитуда мелкой фактуры, метры. Это снежная корка, а не холмы:
     *  выше полуметра наст начинает спорить с дюнами и рельеф читается
     *  комковатым. Ноль — земля стеклянно ровная и выдаёт подделку. */
    амплитуда: 0.45,

    /** Частота первой октавы, 1/метр. Обратная величина — характерный
     *  размер бугра, здесь около двадцати метров. Выше — фактура
     *  превращается в рябь и пропадает под собственным алиасингом на
     *  сетке в метр. */
    частота: 0.05,

    /** Октав. Каждая следующая вдвое чаще и вдвое слабее. Три дают
     *  различимую фактуру на трёх масштабах. Больше пяти — вклад падает
     *  ниже точности сетки, а время построения растёт линейно. */
    октав: 3,
  },

  /** Крупные формы расставляются вручную: шум красив, но кадром не
   *  управляет — холм не поставить туда, где он нужен по композиции.
   *  Радиус меньше трёх метров при сетке в метр превратит дюну в
   *  угловатый шип: нижняя граница именно здесь. */
  дюны: [
    { x: -48, z: -62, радиус: 46, высота: 5.5 },
    { x: 70, z: -30, радиус: 60, высота: 4 },
    { x: 24, z: 78, радиус: 38, высота: 3 },
    { x: -90, z: 40, радиус: 52, высота: 6.5 },
  ] as Дюна[],
}

export const материалСнега = {
  /** Цвет снега. Светлее кирпича намеренно и это важнее всех остальных
   *  настроек: если снег окажется темнее объекта, объект растворится в
   *  фоне. Не чисто белый — чистый белый выбивается в пересвет и теряет
   *  всю светотень, по которой читается рельеф. */
  цвет: '#dfe6ec',

  /** Шероховатость. Высокая намеренно: снег почти не отражает. Ниже 0.6
   *  земля начинает бликовать, ловит свет изнутри сферы и выдаёт белое
   *  пятно под объектом — тот самый пересвет, который слоями не лечится. */
  шероховатость: 0.85,

  /** Металличность. Ноль: снег — диэлектрик. */
  металличность: 0,
}
```

- [ ] **Шаг 6: Написать компонент земли**

Файл `components/scene/Snowfield.tsx`:

```tsx
'use client'

import { useMemo } from 'react'
import { PlaneGeometry } from 'three'

import { материалСнега, рельеф } from '@/lib/config'
import { высотаСцены, локальныеВМировые } from '@/lib/terrain/height'

export default function Snowfield() {
  const геометрия = useMemo(() => {
    const г = new PlaneGeometry(рельеф.размер, рельеф.размер, рельеф.сегментов, рельеф.сегментов)
    const позиции = г.attributes.position

    for (let i = 0; i < позиции.count; i++) {
      const [x, z] = локальныеВМировые(позиции.getX(i), позиции.getY(i))
      // Смещение идёт по локальной оси Z, которая после поворота станет
      // мировой вертикалью.
      позиции.setZ(i, высотаСцены(x, z))
    }

    // Нормали пересчитываются после смещения: без этого вся земля
    // освещается как плоский лист и рельеф не читается вовсе.
    г.computeVertexNormals()
    return г
  }, [])

  return (
    // Четверть оборота вокруг X кладёт плоскость горизонтально.
    // Знак отрицательный — именно он даёт мировую z равной минус
    // локальной y, что учтено в локальныеВМировые.
    <mesh geometry={геометрия} rotation-x={-Math.PI / 2} receiveShadow>
      <meshStandardMaterial
        color={материалСнега.цвет}
        roughness={материалСнега.шероховатость}
        metalness={материалСнега.металличность}
      />
    </mesh>
  )
}
```
