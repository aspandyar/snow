# Выкладка

Хостинг — Vercel. Проект на Next без своих серверных настроек, поэтому
особой подготовки не нужно: Vercel сам определяет framework, команду
сборки и папку вывода. Ничего из этого прописывать руками НЕ надо —
`vercel.json` в репозитории намеренно отсутствует, любая ручная запись
здесь только разойдётся с тем, что делает `npm run build`.

## Что делает владелец

Эти шаги требуют учётной записи, поэтому их делает человек, а не агент.

1. На vercel.com войти через GitHub.
2. **Add New → Project**, выбрать репозиторий `aspandyar/snow`.
3. Ничего не менять в предложенных настройках. Framework определится как
   Next.js, команда сборки `next build`, установка `npm install`.
   Переменных окружения у проекта нет.
4. **Deploy**.

Дальше каждый push в `master` собирается сам, а каждая ветка с открытым
PR получает свой предварительный адрес.

## Что проверить после первой сборки

- **Сцена появилась.** Если холст пуст, а в консоли `Context Lost` —
  смотреть не на код, а на видеокарту гостя: в СБОРКЕ эта беда не
  воспроизводилась ни разу, она живёт только в сервере разработки
  (см. журнал этапа текстур).
- **Стык сцены и страницы.** Кадр обязан сойтись в тот же цвет, которым
  залита страница. Разъедется — виден шов посреди прокрутки.
- **Переключатель языка.** Он читает выбор из localStorage, а на сервере
  localStorage нет: первая разметка всегда русская, сохранённый выбор
  применяется следом. Мигание на долю секунды — так и задумано.
- **Значок вкладки.** Должен быть тёмный шар со светящейся точкой, а не
  треугольник Next: значок заготовки удалён, свой лежит в `app/icon.svg`.

## Вес

Первая загрузка — около шести с половиной мегабайт, из них:

| что | вес |
|---|---|
| карта нормалей снега | 2.2 МБ |
| панорама неба (HDR, 1K) | 1.1 МБ |
| шероховатость снега | 0.7 МБ |
| карта нормалей кирпича | 0.7 МБ |
| весь JavaScript | 1.7 МБ |

Панораму уже уменьшили с 2K до 1K — минус три мегабайта, и в кадре этого
не видно: небо размыто, а как источник освещения оно всё равно
усредняется по полусфере.

Следующий по величине кусок — карта нормалей снега. Трогать её сложнее:
карты нормалей плохо переживают сжатие, а земля видна под скользящим
углом, где мыло заметнее всего. Если вес станет проблемой, начинать надо
с замера на настоящем мобильном соединении, а не с уменьшения наугад.

## Чего в проекте нет и почему

- **Своего домена.** Адрес вида `snow-*.vercel.app` достаточен, пока
  сайт никому не показывают. Домен добавляется в настройках проекта на
  Vercel и кода не касается.
- **Аналитики.** Ни одного стороннего скрипта: страница ничего не
  собирает о зрителе, и добавлять это без причины не стоит.
- **Картинки для ссылки (og:image).** Заголовок и описание для
  мессенджеров есть, картинки нет: снимок сцены пришлось бы обновлять
  вручную при каждой правке кадра, а устаревшая картинка хуже
  отсутствующей.
