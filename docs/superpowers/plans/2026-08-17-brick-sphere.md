# Ледяная сфера из кирпичей — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Собрать сферу из ~500 кирпичей с правильным разворотом кладки, фаской, свечением изнутри и отклонением кирпичей от курсора.

**Architecture:** Раскладка — чистая функция без зависимостей от React и сцены, покрытая тестами. Отрисовка — один `instancedMesh` с геометрией `RoundedBoxGeometry` из drei; матрицы переписываются в `useFrame` через `setMatrixAt`. Курсор ищется аналитическим пересечением луча с невидимой сферой, а не перебором треугольников. Траектории — `<Segments>` из drei только для отклонившихся кирпичей.

**Tech Stack:** three 0.185.1, @react-three/fiber 9.7.0, @react-three/drei 10.7.8, Vitest 4.1.10.

Спека: `docs/superpowers/specs/2026-08-17-brick-sphere-design.md`, раздел 7.
Предыдущий этап: `docs/superpowers/plans/2026-08-17-karkas.md` — должен быть слит в `master`.

## Global Constraints

- **Все числа — только в `lib/config.ts`.** Исключение — тесты: они задают значения у себя, иначе краснеют от безобидной правки настройки.
- **Каждое число в конфиге сопровождается комментарием**: почему именно столько и что сломается иначе.
- **Текст на русском**, пути и имена файлов — латиницей.
- **Ни одной строки самописного шейдера.** Единственный шейдер в проекте — переход, этап 7.
- **`useFrame` вызывается только с приоритетом по умолчанию.** Любой приоритет больше нуля отключает автоматическую отрисовку в R3F, и экран чернеет — при этом ошибок в консоли нет, что делает поломку особенно неприятной.
- **База — `master`**, ветка `ft/sphere`, этап закрывается PR со скриншотами.

```ts
/** Параметры раскладки. Передаются аргументом, а не читаются из конфига:
 *  иначе функцию нельзя протестировать независимо от настроек сцены. */
export type ПараметрыРаскладки = {
  радиус: number
  колец: number
  коэффициент: number
  толщина: number
  шов: number
  смещениеВразбежку: number
}

/** Широта середины кольца, радианы, от северного полюса.
 *
 *  Именно середины. На границе широта нулевого кольца равна нулю, нормаль
 *  совпадает с мировой вертикалью, и векторное произведение для касательной
 *  вырождается в нулевой вектор — базис рассыпается, кирпичи встают как
 *  попало. Полшага сдвига убирают вырождение при любом числе колец. */
export function широтаКольца(колец: number, кольцо: number): number {
  return ((кольцо + 0.5) * Math.PI) / колец
}

/** Сколько кирпичей в кольце.
 *
 *  Синус широты здесь не для красоты: длина кольца равна 2πR·sinθ, и при
 *  делении на это количество синусы сокращаются — ширина кирпича выходит
 *  одинаковой от полюса до экватора. Без синуса кирпичи у полюсов
 *  сплющились бы в иглы.
 *
 *  Единица снизу нужна на случай малого числа колец: округление до нуля
 *  оставило бы кольцо пустым, и в сфере появилась бы сквозная дыра. */
export function количествоВКольце(
  п: Pick<ПараметрыРаскладки, 'колец' | 'коэффициент'>,
  кольцо: number,
): number {
  const широта = широтаКольца(п.колец, кольцо)
  return Math.max(1, Math.round(п.коэффициент * п.колец * Math.sin(широта)))
}
```

```ts
describe('раскладка', () => {
  const кирпичи = разложитьКирпичи(п)
  const ВЕРТИКАЛЬ = new Vector3(0, 1, 0)

  it('кирпичей ровно столько, сколько даёт формула', () => {

      expect(Math.abs(касательная.dot(ВЕРТИКАЛЬ))).toBeLessThan(1e-9)
    }

  it('локальная ось Z смотрит наружу', () => {
    for (const к of кирпичи) {

      expect(нормаль.dot(к.позиция.clone().normalize())).toBeGreaterThan(0.999999)
    }
  })

  it('базис правосторонний', () => {
    // Левосторонний базис вывернет геометрию наизнанку: фаска окажется
    // внутри, а лицевые грани будут отбракованы отсечением задних граней.
    for (const к of кирпичи) {
      const x = new Vector3(1, 0, 0).applyQuaternion(к.кватернион)
      const y = new Vector3(0, 1, 0).applyQuaternion(к.кватернион)
      const z = new Vector3(0, 0, 1).applyQuaternion(к.кватернион)
      expect(new Vector3().crossVectors(x, y).distanceTo(z)).toBeLessThan(1e-9)
    }
  })

  it('поле нормаль совпадает с направлением от центра', () => {
    for (const к of кирпичи) {
      expect(к.нормаль.length()).toBeCloseTo(1, 10)
      expect(к.нормаль.dot(к.позиция.clone().normalize())).toBeGreaterThan(0.999999)
    }
  })
})
```

```ts
import { Matrix4, Quaternion, Vector3 } from 'three'

export type Кирпич = {
  позиция: Vector3
  кватернион: Quaternion
  масштаб: Vector3
  нормаль: Vector3
  кольцо: number
  номерВКольце: number
}

const ВЕРТИКАЛЬ = new Vector3(0, 1, 0)

export function разложитьКирпичи(п: ПараметрыРаскладки): Кирпич[] {
  const кирпичи: Кирпич[] = []
  const радиусЦентров = п.радиус - п.толщина / 2

  for (let кольцо = 0; кольцо < п.колец; кольцо++) {
    const широта = широтаКольца(п.колец, кольцо)
    const количество = количествоВКольце(п, кольцо)

    for (let номер = 0; номер < количество; номер++) {
      const долгота = (номер * 2 * Math.PI) / количество

      const нормаль = new Vector3(
        Math.sin(широта) * Math.cos(долгота),
        Math.cos(широта),
        Math.sin(широта) * Math.sin(долгота),
      )

      // Полный базис из трёх осей, а не поворот «из вектора в вектор».
      // Поворот между двумя векторами оставляет вращение вокруг нормали
      // незакреплённым: сфера соберётся, но кирпичи будут стоять пьяно.
      // Это самая коварная из ошибок — она проявляется не сразу.
      const касательная = new Vector3().crossVectors(ВЕРТИКАЛЬ, нормаль).normalize()
      const меридиан = new Vector3().crossVectors(нормаль, касательная)

      // Порядок столбцов задаёт соответствие локальных осей геометрии:
      // X вдоль кольца (ширина), Y вдоль меридиана (высота), Z по нормали
      // (толщина). Базис правосторонний: касательная × меридиан = нормаль.
      const кватернион = new Quaternion().setFromRotationMatrix(
        new Matrix4().makeBasis(касательная, меридиан, нормаль),
      )

      кирпичи.push({
        позиция: нормаль.clone().multiplyScalar(радиусЦентров),
        кватернион,
        масштаб: new Vector3(1, 1, 1),
        нормаль,
        кольцо,
        номерВКольце: номер,
      })
    }
  }

  return кирпичи
}
```

**Interfaces:**

- Produces: `размерыКирпича(п: ПараметрыРаскладки): { ширина: number; высота: number; толщина: number }`; поле `масштаб` в `Кирпич` перестаёт быть единичным.

Размеры выносятся отдельной функцией потому, что ими пользуется и раскладка (для поправки на округление), и компонент отрисовки (для построения геометрии). Иначе формула разошлась бы по двум файлам.

- [ ] **Шаг 1: Написать падающий тест**

Дописать в `tests/bricks.test.ts` (импорт дополнить `размерыКирпича`):

```ts
describe('размеры и масштаб', () => {
  const размеры = размерыКирпича(п)
  const кирпичи = разложитьКирпичи(п)

  it('кирпич вытянут ровно два к одному при коэффициенте 1', () => {
    expect(размеры.ширина / размеры.высота).toBeCloseTo(2, 12)
    expect(размеры.ширина).toBeCloseTo(1.3463968515, 8)
    expect(размеры.высота).toBeCloseTo(0.6731984258, 8)
  })

  it('коэффициент 2 даёт квадратную плитку', () => {
    const квадрат = размерыКирпича({ ...п, коэффициент: 2 })
    expect(квадрат.ширина / квадрат.высота).toBeCloseTo(1, 12)
  })

  it('масштаб по высоте и толщине одинаков у всех кирпичей', () => {
    for (const к of кирпичи) {
      expect(к.масштаб.y).toBeCloseTo(1 - п.шов, 12)
      expect(к.масштаб.z).toBeCloseTo(1, 12)
    }
  })

  it('вне полюсных колец ширина отклоняется меньше чем на 5%', () => {
    // Синусы в формуле сокращаются, поэтому ширина точно постоянна.
    // Портит её только округление количества, и заметно — лишь у полюсов.
    for (const к of кирпичи) {
      if (к.кольцо < 2 || к.кольцо > п.колец - 3) continue
      expect(к.масштаб.x / (1 - п.шов)).toBeGreaterThan(0.95)
      expect(к.масштаб.x / (1 - п.шов)).toBeLessThan(1.05)
    }
  })

  it('на полюсных кольцах ширина заметно меньше — это известное искажение', () => {
    // Округление 1.57 до 2 сужает кирпич на 21.5%. Затронуто по два
    // кирпича на полюс из 506. Тест фиксирует величину, чтобы она не
    // выросла незаметно при смене числа колец.
    const полюс = кирпичи.filter((к) => к.кольцо === 0)
    expect(полюс).toHaveLength(2)
    for (const к of полюс) {
      expect(к.масштаб.x / (1 - п.шов)).toBeCloseTo(0.785, 2)
    }
  })

  it('нечётные кольца сдвинуты вразбежку на полшага', () => {
    const первыйЧётного = кирпичи.find((к) => к.кольцо === 2 && к.номерВКольце === 0)!
    const первыйНечётного = кирпичи.find((к) => к.кольцо === 3 && к.номерВКольце === 0)!
    const долгота = (к: Кирпич) => Math.atan2(к.нормаль.z, к.нормаль.x)
    expect(Math.abs(долгота(первыйЧётного))).toBeLessThan(1e-9)
    expect(Math.abs(долгота(первыйНечётного))).toBeGreaterThan(1e-3)
  })

  it('соседи в кольце не пересекаются', () => {
    const радиусЦентров = п.радиус - п.толщина / 2
    for (const к of кирпичи) {
      const широта = широтаКольца(п.колец, к.кольцо)
      const количество = количествоВКольце(п, к.кольцо)
      const угловойШаг = (2 * Math.PI) / количество
      const угловаяШирина =
        (размеры.ширина * к.масштаб.x) / (радиусЦентров * Math.sin(широта))
      expect(угловаяШирина).toBeLessThan(угловойШаг)
    }
  })
```

```ts
/** Номинальные размеры кирпича в метрах.
 *
 *  Эти размеры запекаются прямо в геометрию, а не задаются масштабом.
 *  Так фаска остаётся правильной по построению: масштаб правит только
 *  погрешность округления количества, а она мала везде, кроме полюсов.
 *
 *  Отношение ширины к высоте равно 2/коэффициент. При коэффициенте 2
 *  выходит точный квадрат — плитка, а не кладка. */
export function размерыКирпича(п: ПараметрыРаскладки) {
  return {
    ширина: (2 * Math.PI * п.радиус) / (п.коэффициент * п.колец),
    высота: (Math.PI * п.радиус) / п.колец,
    толщина: п.толщина,
  }
}
```

```tsx
'use client'

import { RoundedBoxGeometry } from '@react-three/drei'
import { useLayoutEffect, useMemo, useRef } from 'react'
import { InstancedMesh, Matrix4 } from 'three'

import { материалКирпича, сфера } from '@/lib/config'
import { размерыКирпича, разложитьКирпичи } from '@/lib/layout/bricks'

export default function BrickSphere() {
  const ссылка = useRef<InstancedMesh>(null)
  const кирпичи = useMemo(() => разложитьКирпичи(сфера), [])
  const размеры = useMemo(() => размерыКирпича(сфера), [])

  useLayoutEffect(() => {
    const меш = ссылка.current
    if (!меш) return
    const матрица = new Matrix4()
    for (let i = 0; i < кирпичи.length; i++) {
      const к = кирпичи[i]
      матрица.compose(к.позиция, к.кватернион, к.масштаб)
      меш.setMatrixAt(i, матрица)
    }
    меш.instanceMatrix.needsUpdate = true
  }, [кирпичи])

  return (
    <instancedMesh
      ref={ссылка}
      // Геометрия и материал приходят детьми, поэтому первые два
      // аргумента конструктора пустые. Третий — предельное число
      // инстансов, изменить его после создания нельзя.
      args={[undefined!, undefined!, кирпичи.length]}
    >
      <RoundedBoxGeometry
        args={[размеры.ширина, размеры.высота, размеры.толщина]}
        radius={размеры.толщина * материалКирпича.фаска}
        smoothness={материалКирпича.гладкостьФаски}
      />
      <meshStandardMaterial
        color={материалКирпича.цвет}
        roughness={материалКирпича.шероховатость}
        metalness={материалКирпича.металличность}
        flatShading
      />
    </instancedMesh>
  )
}
```

```tsx
'use client'

import { Segment, Segments } from '@react-three/drei'
import { useMemo } from 'react'
import { Vector3 } from 'three'

import { отладка, сфера } from '@/lib/config'
import { разложитьКирпичи } from '@/lib/layout/bricks'

/** Три оси базиса каждого N-го кирпича: красная вдоль кольца, зелёная
 *  вдоль меридиана, синяя по нормали. Если красные оси где-то кренятся
 *  относительно горизонта — базис собран неправильно. Это единственный
 *  способ увидеть ошибку до того, как её замаскирует фаска. */
export default function BrickAxes() {
  const оси = useMemo(() => {
    const кирпичи = разложитьКирпичи(сфера)
    const результат: { начало: Vector3; конец: Vector3; цвет: string }[] = []

    for (let i = 0; i < кирпичи.length; i += отладка.шагВыборки) {
      const к = кирпичи[i]
      const направления: [Vector3, string][] = [
        [new Vector3(1, 0, 0).applyQuaternion(к.кватернион), '#d64545'],
        [new Vector3(0, 1, 0).applyQuaternion(к.кватернион), '#4a9e5c'],
        [new Vector3(0, 0, 1).applyQuaternion(к.кватернион), '#3f6fd8'],
      ]
      for (const [направление, цвет] of направления) {
        результат.push({
          начало: к.позиция.clone(),
          конец: к.позиция.clone().addScaledVector(направление, отладка.длинаОси),
          цвет,
        })
      }
    }
    return результат
  }, [])

  if (!отладка.осиВидны) return null

  return (
    <Segments limit={оси.length} lineWidth={отладка.толщинаЛинии}>
      {оси.map((ось, i) => (
        <Segment key={i} start={ось.начало} end={ось.конец} color={ось.цвет} />
      ))}
    </Segments>
  )
}
```

```ts
import type { Vector3 } from 'three'

/** Плавный переход от нуля к единице между двумя краями. */
export function сглаженныйПереход(край0: number, край1: number, значение: number): number {
  const t = Math.min(1, Math.max(0, (значение - край0) / (край1 - край0)))
  return t * t * (3 - 2 * t)
}

/** На сколько метров кирпич должен отойти от поверхности.
 *
 *  Сравнение идёт по косинусу угла, а не по самому углу: арккосинус на
 *  полтысячи кирпичей в каждом кадре не нужен, а порог переводится в
 *  косинус один раз при чтении конфига. */
export function цельСмещения(
  нормаль: Vector3,
  направлениеНаКурсор: Vector3 | null,
  косинусГраницы: number,
  максСмещение: number,
): number {
  if (!направлениеНаКурсор) return 0
  const косинус = нормаль.dot(направлениеНаКурсор)
  return максСмещение * сглаженныйПереход(косинусГраницы, 1, косинус)
}

/** Подтягивание текущего значения к цели за шаг времени.
 *
 *  Экспонента, а не постоянная доля: доля привязала бы скорость возврата
 *  к частоте кадров, и на слабой машине кирпичи возвращались бы медленнее,
 *  чем на быстрой. С экспонентой два полушага в точности равны одному
 *  целому шагу. */
export function подтянуть(
  текущее: number,
  цель: number,
  скорость: number,
  шаг: number,
): number {
  return текущее + (цель - текущее) * (1 - Math.exp(-скорость * шаг))
}
```

```tsx
'use client'

import { RoundedBoxGeometry } from '@react-three/drei'
import { useFrame } from '@react-three/fiber'
import { useLayoutEffect, useMemo, useRef } from 'react'
import { InstancedMesh, Matrix4, Sphere, Vector3 } from 'three'

import { материалКирпича, наведение, сфера } from '@/lib/config'
import { подтянуть, цельСмещения } from '@/lib/hover/displacement'
import { размерыКирпича, разложитьКирпичи } from '@/lib/layout/bricks'

export default function BrickSphere() {
  const ссылка = useRef<InstancedMesh>(null)
  const кирпичи = useMemo(() => разложитьКирпичи(сфера), [])
  const размеры = useMemo(() => размерыКирпича(сфера), [])

  // Смещения живут в обычном массиве, а не в состоянии React: они
  // меняются каждый кадр, и перерисовка компонента на каждое движение
  // мыши положила бы страницу.
  const смещения = useRef(new Float32Array(кирпичи.length))

  // Невидимая гладкая сфера для луча. Пересечение с ней считается
  // аналитически. Луч по самим инстансам перебирал бы все 506 копий по
  // полторы сотни треугольников — семьдесят пять тысяч проверок на
  // каждое движение мыши, а их до ста двадцати в секунду.
  const сфераЛуча = useMemo(() => new Sphere(new Vector3(0, 0, 0), сфера.радиус), [])
  const косинусГраницы = useMemo(() => Math.cos(наведение.угловойРадиус), [])

  // Все рабочие объекты выделяются один раз. Создавать вектор или матрицу
  // внутри кадра — значит выбрасывать шестьдесят объектов в секунду
  // сборщику мусора, а он останавливает кадр в непредсказуемый момент.
  const точка = useRef(new Vector3())
  const направлениеНаКурсор = useRef(new Vector3())
  const матрица = useRef(new Matrix4())
  const положение = useRef(new Vector3())

  useLayoutEffect(() => {
    смещения.current.fill(0)
  }, [кирпичи])

  // Приоритет по умолчанию. Любой приоритет больше нуля отключает
  // автоматическую отрисовку в R3F, и экран чернеет без единой ошибки
  // в консоли.
  useFrame((состояние, шаг) => {
    const меш = ссылка.current
    if (!меш) return

    состояние.raycaster.setFromCamera(состояние.pointer, состояние.camera)
    const попал = состояние.raycaster.ray.intersectSphere(сфераЛуча, точка.current)
    const направление = попал
      ? направлениеНаКурсор.current.copy(точка.current).normalize()
      : null

    for (let i = 0; i < кирпичи.length; i++) {
      const к = кирпичи[i]
      const цель = цельСмещения(к.нормаль, направление, косинусГраницы, наведение.максСмещение)
      смещения.current[i] = подтянуть(смещения.current[i], цель, наведение.скорость, шаг)

      положение.current.copy(к.позиция).addScaledVector(к.нормаль, смещения.current[i])
      матрица.current.compose(положение.current, к.кватернион, к.масштаб)
      меш.setMatrixAt(i, матрица.current)
    }
    меш.instanceMatrix.needsUpdate = true
  })

  return (
    <instancedMesh ref={ссылка} args={[undefined!, undefined!, кирпичи.length]}>
      <RoundedBoxGeometry
        args={[размеры.ширина, размеры.высота, размеры.толщина]}
        radius={размеры.толщина * материалКирпича.фаска}
        smoothness={материалКирпича.гладкостьФаски}
      />
      <meshPhysicalMaterial
        color={материалКирпича.цвет}
        roughness={материалКирпича.шероховатость}
        metalness={материалКирпича.металличность}
        sheen={материалКирпича.контурноеСвечение}
        sheenRoughness={материалКирпича.шероховатостьСвечения}
        sheenColor={материалКирпича.цветСвечения}
      />
    </instancedMesh>
  )
}
```

**Interfaces:**

Отрезков рисуется не 506, а столько, сколько кирпичей реально отклонилось. Предел задаётся один раз при создании и меняться не может, поэтому берётся с запасом от углового радиуса.

```tsx
'use client'

import { Segment, Segments, type SegmentObject } from '@react-three/drei'
import { useFrame } from '@react-three/fiber'
import { useMemo, useRef, type RefObject } from 'react'

import { материалКирпича, наведение, отладка, сфера } from '@/lib/config'
import type { Кирпич } from '@/lib/layout/bricks'

type Свойства = {
  кирпичи: Кирпич[]
  смещения: RefObject<Float32Array>
}

export default function Trajectories({ кирпичи, смещения }: Свойства) {
  // Предел числа отрезков задаётся при создании и потом не меняется.
  // Доля затронутых кирпичей равна (1 − cos α)/2; берём вдвое больше
  // расчётного, чтобы запас покрыл неравномерность кладки у полюсов.
  const предел = useMemo(() => {
    const доля = (1 - Math.cos(наведение.угловойРадиус)) / 2
    return Math.max(8, Math.ceil(кирпичи.length * доля * 2))
  }, [кирпичи])

  const ссылки = useRef<(SegmentObject | null)[]>([])

  useFrame(() => {
    let занято = 0
    for (let i = 0; i < кирпичи.length && занято < предел; i++) {
      const смещение = смещения.current[i]
      if (смещение <= наведение.порогТраектории) continue
      const отрезок = ссылки.current[занято]
      if (!отрезок) break
      отрезок.start.copy(кирпичи[i].позиция)
      отрезок.end.copy(кирпичи[i].позиция).addScaledVector(кирпичи[i].нормаль, смещение)
      занято++
    }
    // Неиспользованные отрезки схлопываются в точку: скрыть отдельный
    // отрезок в <Segments> нельзя, но нулевая длина не рисует ничего.
    for (let i = занято; i < предел; i++) {
      const отрезок = ссылки.current[i]
      if (отрезок) отрезок.end.copy(отрезок.start)
    }
  })

  return (
    <Segments limit={предел} lineWidth={отладка.толщинаЛинии}>
      {Array.from({ length: предел }, (_, i) => (
        <Segment
          key={i}
          ref={(узел) => {
            ссылки.current[i] = узел
          }}
          start={[0, сфера.радиус, 0]}
          end={[0, сфера.радиус, 0]}
          color={материалКирпича.цветСвечения}
        />
      ))}
    </Segments>
  )
}
```

## Известные дефекты, которые допустимо оставить

**Фаска на полюсных кирпичах растянута.** Округление количества с 1.57 до 2 сужает кирпич на 21.5%, и вместе с ним сужается скругление. Затронуто по два кирпича на каждом полюсе из 506. Если на скриншоте задачи 5 это видно — записать в PR и лечить отдельной задачей: полюсные кольца выносятся во второй инстансированный меш со своей геометрией.

**Тени не включены.** `castShadow` и `receiveShadow` появятся на этапе 2 вместе с землёй: без поверхности, на которую падает тень, включать их бессмысленно.
