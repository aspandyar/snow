# snow

Одностраничный сайт с трёхмерной сценой: ледяная сфера из кирпичей над
заснеженной равниной. Прокрутка ведёт камеру, в конце играет переход,
и открывается лендинг с разбором того, как эта сцена устроена.

## Запуск

    npm install
    npm run dev

## Тесты

    npm test

## Устройство

Все числовые константы живут в `lib/config.ts`. Больше нигде в проекте
чисел нет. Настройка сцены сводится к правке одного файла; каждое число
сопровождается комментарием, объясняющим, почему оно именно такое.

Спеки и планы — в `docs/superpowers/`.
